# Анализ продаж (BigQuery + ClickHouse)

**Технологии:** BigQuery, ClickHouse (chDB), pandas, plotly

**Задачи:**
- Выгрузка данных из BigQuery
- SQL-анализ: топ города, топ товары, оконные функции
- Детекция аномалий (3 сигмы)
- Гео-визуализация на карте

**Результат:** выявлены города-лидеры, сезонность пик в ноябре, аномалии продаж
